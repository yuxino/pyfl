# Experimental initials data: source and attribution

These source records generate the opt-in modern entries in Pyfl 2.1.0. They do
not replace the legacy default dictionary. The production package preserves the
upstream notices in THIRD_PARTY_NOTICES.

## Direct inputs

The generator reads two files from
[mozillazg/pinyin-data at 923b108dc5d45dee061324c011b478fb649f8b73](https://github.com/mozillazg/pinyin-data/tree/923b108dc5d45dee061324c011b478fb649f8b73):

- `pinyin.txt`: the complete combined character-pronunciation inventory in that snapshot.
- `kMandarin_8105.txt`: the preferred single reading for the 8,105 characters in the 2013 General Standard Chinese Characters Table, including upstream manual corrections.

The fixed source commit is dated February 23, 2026 and updates the upstream
Unihan data to Unicode 17.0.0. Exact URLs, byte counts and SHA-256 hashes of all
inputs and notices are recorded in [source-lock.json](source-lock.json).

[`src/modern/data/common.json`](../../../src/modern/data/common.json) contains the
common inventory. [`full.json`](../../../src/modern/data/full.json) contains the
full inventory, with the common preferred reading applied wherever present.
Both files obtain alternative readings for their characters from `pinyin.txt`.
The chosen default initial is placed first; the remaining distinct initials retain
the upstream reading order. The full table's first reading outside the common
inventory is an upstream default, not a claim of frequency or contextual accuracy.
Candidates may include historical or rare readings.

The generated `*-ranges.json` and `*-alternatives.json` files in the same source
directory separate runtime conversion from candidate search data. They are
verified against the same locked records and are not imported together by
conversion-only entries.

Only the first ASCII Latin letter after NFD decomposition and combining-mark
removal is retained. Tone, remaining syllable letters and duplicate initials are
discarded. This is first-letter conversion, not full pinyin or full shengmu output.
Invalid default readings are omitted and reported instead of guessed. A `.` in a
range represents an unknown code point, not an output character. Ranges split
when there are more than 64 consecutive missing code points. `entries` counts only
known code points, excluding holes. Supplementary code points use their full
numeric scalar value and alternatives use the actual Unicode character as key.

## Notices and upstream provenance

- The direct pinyin-data repository carries the MIT notice, copyright 2016
  mozillazg. Its unmodified original is [pinyin-data-MIT.txt](licenses/pinyin-data-MIT.txt).
- pinyin-data explicitly derives readings from the Unicode Unihan database and
  names its other dictionary and manual-correction sources. The original pinned
  [upstream README](upstream/pinyin-data-README.md) is included to retain that
  attribution chain. Its relative file links refer to the upstream repository.
- Unicode data has its own terms; it is not relabeled MIT. The unmodified
  [Unicode License V3](licenses/Unicode-License-V3.txt) and
  [Unicode 17 UCD ReadMe](upstream/Unicode-17-ReadMe.txt) are included. The license
  permits data modification and distribution subject to retaining the copyright
  and permission notice with the data/software or associated documentation.
- This generator does not download or merge phrase-pinyin-data, CC-CEDICT, or any
  full phrase dictionary. The included upstream README names additional sources
  used across that upstream project; this notice does not make a separate rights
  claim about every original dictionary mentioned there.

The current official Unicode license URL is content-locked by SHA-256, although
the server may update that URL in the future. If its bytes change, generation
fails rather than silently accepting new terms. The preserved original notice
and verified local cache keep the reviewed content available.

## Reproduction

From the repository root, with Node.js 22 or 24:

```sh
node experimental/initials/scripts/generate-data.mjs
node experimental/initials/scripts/generate-data.mjs --offline --check
```

The first command downloads only missing inputs into the ignored
`experimental/initials/.cache/` directory, verifies their pinned hashes, then
generates the tables, counts and original-notice copies. Existing cache entries
must also match their pinned hashes. `--offline --check` performs no network
requests and checks exact generated bytes without rewriting the data files.
The generated files contain no clock timestamps, so repeated runs are stable.

Coverage, invalid readings, default overrides, alternatives and the full table's
missing legacy characters are listed in [generation-report.json](generation-report.json).
Coverage is limited to the selected source records, not all Unicode Han characters.
